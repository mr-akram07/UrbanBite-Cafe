# UrbanBite Cafe - Restaurant Table Booking & Waitlist System

A fullstack modern web application for restaurant table reservation, dynamic waitlist management, and owner administration dashboard.

---

## 🚀 Features

- **Table Booking Flow**: Date & time slot picker, party size selection, real-time availability check, instant booking confirmation with unique booking IDs.
- **Dynamic Waitlist**: Real-time queue position tracking, estimated wait times, and party management.
- **Booking Management**: Lookup and cancel existing reservations seamlessly.
- **Admin / Owner Dashboard**: Manage floor tables, live reservations, active waitlists, and cafe settings.
- **Theming**: Dark/Light mode support with responsive, high-performance UI.

---

## 🛠️ Tech Stack

### Frontend (Client)
- **React 19** + **Vite**
- **Lucide Icons** & **Canvas Confetti**
- **Vanilla CSS** with modern design tokens

### Backend (Server)
- **Node.js** + **Express**
- **MongoDB** / **Mongoose** (with file-based JSON fallback support)
- **CORS** & **Dotenv**

---

## 📦 Setup & Installation

### 1. Prerequisites
- Node.js (v18+)
- npm or yarn

### 2. Backend Setup
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### 3. Frontend Setup
```bash
cd client
npm install
cp .env.example .env
npm run dev
```
